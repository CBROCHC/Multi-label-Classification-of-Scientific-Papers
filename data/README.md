# Data

The datasets are **not redistributed** in this repository. They come from the course competition on Codabench (registration required) and are derived from the public [arXiv paper abstracts dataset](https://www.kaggle.com/datasets/spsayakpaul/arxiv-paper-abstracts/data) on Kaggle.

Expected files:

| File | Rows | Columns |
|---|---|---|
| `dataset_train.csv` | 43,555 | `titles`, `summaries`, `terms` (list of arXiv categories) |
| `dataset_test.csv` | 4,885 | `titles`, `summaries`, `keywords` (unlabeled; `keywords` not used) |

Place both files in this folder (they are git-ignored). Embedding caches (`*.npy`, `*.npz`) generated by the notebooks should also stay out of version control.
